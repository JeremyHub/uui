UUI

An app that generates itself as you use it. Describe an app, new or existing, and use the one the model makes for you. Every screen is written on the fly.

  1. Describe an app. The model writes the first screen, which streams into the page as it is generated.
  2. Click around. Each click sends the model what is on screen and what has happened so far in the session.
  3. The page reacts. The model rewrites the parts of the page that need to change.
  • Simple interactions stay local. Tabs, toggles and sorting run in the page and never wait on the model.
  • It can use real data. The model can fetch an API before it answers, so a weather page shows the actual weather.
  • It remembers the session. Earlier choices are kept in a short summary, so the app stays consistent.
  • It runs anywhere. Through Ollama on your machine, in this tab over WebGPU with no server, or on your Claude subscription.
